# 마이 워크플래너

연차, 프로젝트 휴가, 회사·개인 일정과 행사를 한곳에서 관리하는 개인용 웹사이트입니다.

## 실행 방법

- **평소 사용:** `index.html`을 더블클릭해서 크롬이나 엣지로 열고, 즐겨찾기에 등록해 두세요. VS Code를 켜지 않아도 됩니다.
- **코드 수정:** VS Code에서 수정하고 저장한 뒤, 브라우저에서 F5를 누르면 반영됩니다.
- **처음 열었을 때:** 설정 탭에서 이름과 입사일을 입력하세요.

> 주소(`file:///…`와 Live Server 주소)마다 데이터가 따로 저장됩니다. 한 주소로만 쓰고, **설정 → 자동 저장**에서 파일을 연결해 두면 안전합니다.

## 메뉴별 기능

| 메뉴 | 기능 |
|---|---|
| 🏠 홈 | KPI(연차·프로젝트 휴가·오늘 일정·다음 휴가), 소멸·만료 경고, 오늘·7일 일정, 진행 중인 행사, 월간 달력 |
| 📅 캘린더 | 월간/주간 전환, 회사·개인·행사 필터, 일정을 끌어서 날짜 이동, 주간 보기에서 시간대를 클릭해 바로 추가 |
| 🎪 행사 | 셋업·본행사·철수 기간, 클라이언트·장소·색상, 체크리스트와 진행률, 기간 중 주말근무 날짜별 프로젝트 휴가 적립, 연결된 일정 |
| 🌴 휴가 | 연차 계산 근거, 프로젝트 휴가 규정, 징검다리 연휴 추천과 원클릭 등록, 사용·적립 내역(사용기한·소멸 표시) |
| 📊 리포트 | 연도별 연차·프로젝트 휴가·주말근무·행사 통계, 월별 그래프, 한 해 요약 |
| 🔍 검색 | 일정 제목·메모, 행사명·클라이언트·장소·체크리스트 검색 (단축키 `/`) |
| ⚙️ 설정 | 기본 정보, 보정값, 프로젝트 휴가 '월말' 기준, 화면 모드, 자동 저장, 백업 |

## 휴가 규칙

- **연차 (근로기준법 제60조, 입사일 기준)**
  - 1년 미만: 1개월 개근마다 1일, 최대 11일
  - 1년 이상: 15일, 이후 2년마다 1일 가산(최대 25일)
  - 기간 만료 60일 전부터 홈에 미사용 연차 경고가 표시됩니다.
- **프로젝트 휴가 (회사 규정)**
  - 주말근무로 적립한 휴가는 근무한 달 말일까지 사용합니다.
  - 근무일이 말일로부터 7일 이내(월말 주말)면 다음 달 말일까지 사용할 수 있습니다. 이 기준 일수는 설정에서 변경할 수 있습니다.
  - 사용할 때는 만료가 빠른 적립분부터 자동으로 차감되고, 만료 14일 전부터 경고가 표시됩니다.
- 여러 날 휴가는 주말과 공휴일(`holidays.js`)을 빼고 계산합니다.

## 일정 입력 팁

| 하고 싶은 것 | 방법 |
|---|---|
| 연차·반차 | 구분 **개인** → 휴가 사용 선택 |
| 주말근무 적립 | 구분 **회사** → 주말근무 적립 1일/0.5일 |
| 행사에 연결 | 일정 팝업의 **행사 연결**에서 선택 |
| 반복 일정 | 반복(매일/평일/매주/매월)과 종료일 선택. 특정 날짜만 지우려면 그 날의 일정을 열어 "이 날만 삭제" |

## PC·휴대폰 동기화

- 온라인 주소(GitHub Pages)에서 **구글 계정으로 로그인**하면 데이터가 Firebase(Firestore)에 저장되어 PC와 휴대폰에서 같은 내용을 볼 수 있습니다.
- 처음 로그인할 때 그 기기의 데이터가 온라인에 올라가고, 이후 수정하면 자동으로 동기화됩니다.
- 인터넷이 끊겨도 입력할 수 있고, 연결되면 자동으로 저장됩니다.
- 휴대폰에서는 브라우저 메뉴의 **"홈 화면에 추가"** 로 앱처럼 쓸 수 있습니다.
- 설정값은 `firebase-config.js`에 있습니다. PC 파일(`file:///`)로 열면 로그인할 수 없으니 온라인 주소를 사용하세요.

```
├── holidays.js  공휴일 목록 (회사 휴무일도 여기에 추가)

```
